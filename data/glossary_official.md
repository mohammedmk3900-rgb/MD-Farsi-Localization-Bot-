هدف:
مرجع رسمی انتخاب و استفاده از اصطلاحات فارسی در پروژه.
هدف ترجمه صرف کلمات نیست؛ ترجمه باید «مفهومی، یکپارچه، طبیعی و قابل فهم برای گیمر فارسی‌زبان» باشد.
هر اصطلاح باید بر اساس نقش و معنای آن در Millennium Dawn ترجمه شود، نه صرفاً معنی لغوی انگلیسی.

قوانین:
1. ثبات اصطلاحات: هر اصطلاح ثبت و نهایی‌شده باید در سراسر پروژه با همان معادل استفاده شود.
Example "Hegemony" → سلطه; alternatives like «هژمونی» or «برتری» without formal review are not accepted.
2. ترجمه مفهومی: قابل فهم برای بازیکن؛ ترجمه تحت‌اللفظی/ماشینی/بیش از حد دانشگاهی در صورت انتقال ضعیف مفهوم اولویت ندارد.
3. یکپارچگی: یک اصطلاح بدون دلیل معنایی نباید در بخش‌های مختلف پروژه چند ترجمه متفاوت داشته باشد.
4. حفظ عناصر فنی: `$ROOT$`, `§`, `£`, variables, scopes, script tags etc. unchanged.
5. اصطلاحات جدید: unlisted term has no fixed project equivalent; proposal may be used until approved.
6. تغییر اصطلاحات ثابت: not changed by personal taste; reasons can include semantic issue, game usage incompatibility, ambiguity, more precise/natural equivalent, version meaning change. Approved changes logged.
