# Genesis Polyglot Engine

Explicit ownership per language:
- Python: control plane and domain orchestration
- Rust: deterministic localization QA
- Go: background workers
- TypeScript: typed contracts and dashboard integration
- C++: optional native performance primitives
- C#: optional Windows integration
- Lua: controlled extension rules
- SQL: persistent data and analytics

Components communicate through versioned contracts; a language is added only when its subsystem has a real responsibility.
