# MD-Farsi-Localization-Bot-

## 📡 Project Command Center

A premium, automatically updated dashboard for Millennium Dawn Farsi Localization.

**Dashboard:** `https://mohammedmk3900-rgb.github.io/MD-Farsi-Localization-Bot-/`

It visualizes live ParaTranz statistics, translation/review progress, file coverage, milestones, participant count, and synchronization time. The public dashboard contains no ParaTranz token; GitHub Actions generates a safe data snapshot using the repository secret.
